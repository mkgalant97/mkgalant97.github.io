# Maintaining Misha Galant's website

The easiest way to change the site is to open Claude Code in this folder and say what should change, for example "add a recital on March 3 at Libby Gardner Hall."

## Where things are

| What | Where |
|---|---|
| Bio, home intro, news, email, social links, PayPal, form IDs | `data/content.json` |
| Concerts (upcoming and past) | `data/events.json` |
| Videos (YouTube IDs) | `data/videos.json` |
| Mountain trip list (title, date, cover photo) | `data/trips.json` |
| Trip report text and photos | `data/trips/<slug>.html` |
| Colors, fonts, layout | `assets/style.css` |
| Photos and audio | `assets/img/`, `assets/audio/` |
| Page templates | `build.py` |

`docs/` is generated by the build. **Don't edit it by hand,** because every build overwrites it.

## Making a change

1. Edit a file in `data/`.
2. Run `python3 build.py --serve` and open http://localhost:8000/. Press Ctrl+C to stop the preview.
3. Publish it: `git add -A && git commit -m "Describe the change" && git push`. The live site updates within about a minute.

Live site: https://mkgalant97.github.io/ (repo `mkgalant97/mkgalant97.github.io`, served from `main:/docs`).

## Concerts

Add an entry to `data/events.json`. Concerts dated today or later appear under Upcoming. Once the date passes, the next build moves them to Past performances. For a multi-day event, add `"end": "YYYY-MM-DD"`.

```json
{"date": "2027-03-03", "display_date": "3 March 2027", "time": "7:30 pm",
 "title": "Solo Recital",
 "program": [{"composer": "Medtner", "work": "Sonata in E minor, op. 25 no. 2"}],
 "with": [], "venue": "Libby Gardner Concert Hall", "city": "Salt Lake City, UT, USA",
 "link": {"label": "Tickets", "url": "https://..."}}
```

## Videos

Add `{"id": "<YouTube ID>", "composer": "...", "work": "..."}` to `data/videos.json`. The ID is the part after `v=` in the YouTube URL. The first three videos also appear on the home page.

## Lessons and Contact forms

These are your existing Google Forms, embedded on the page. Responses arrive wherever they did before. To use a different form, paste its ID (the long code in the form's link, after `/d/e/`) into `lessons_form` or `contact_form` in `data/content.json`.

## Old Columbia links

Old addresses such as `about.html` and `devilscastle.html` redirect to the new pages. To send visitors from the Columbia site to here, replace `~/public_html/index.html` on cunix with a redirect to https://mkgalant97.github.io/.
